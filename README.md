## 🏠 Otto The Home Device
This application is called Otto and it is meant to act as a smart home device that keeps track of the location of the users
belongings in each room. The user can easily check each room to see the items that are located there, edit the list for each
room when a new belonging is left in the room, and create new list for other parts of the house that don't have an assigned list.
## ✨ Technologies
- C++
- CLI
- File IO
## 🚀 Features
- Text File Editing
- Text File Saving
- Text File Viewing
## 📌 The Reason
The main goals that I had in mind while making this application was creating an app that can read the data within .txt files,
enable the application to create brand new text files, enable the application to edit .txt files, and enable the application to
display the contents of a .txt file to the console.
## 📖 How To Use
Immediately upon running the application the user has the option of viewing a list, editing a list, or making a new list. These
list contains items that belong in each room of the simulated house. If you place an item in a room then you can add that to 
the list. If the user is looking for an item you can just view each list for each room to find the item. If the user wants to
create a brand new list for an area within the house then they can do that aswell.
